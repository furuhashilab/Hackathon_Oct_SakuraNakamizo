# 慶良間諸島ダイビングスポット診断

**古橋研究室オンラインハッカソン2026-2027「10月 FOSS4G Hiroshima / SotM Asia OSAKA 振り返りハッカソン」**
制作：中溝さくら（FuruhashiLab）

---

## 作品の概要と制作目的

慶良間諸島（沖縄県）に限定した、初心者向けの「ダイビングスポット診断」Web アプリです。
3つの質問に答えると、おすすめのスポット候補（上位3件）が、紹介文・ワンポイント・出典つきで表示されます。

慶良間諸島は2014年3月5日に国立公園に指定された、透明度の高い海で知られるエリアです。
この診断は、初心者が「どこから調べればいいか」の手がかりを得られるようにすることを目的にしています。

> [!WARNING]
> この診断は趣味・学習目的の簡易的なものです。**海況・安全性・生き物との遭遇を保証するものではありません。**
> 実際に潜る・泳ぐ際は、必ず現地のダイビングショップやガイドに相談し、当日の気象・海況情報と指示に従ってください。
> スポット情報は公開資料をもとにまとめていますが、内容が変わっている可能性があります。最新情報は各村・観光協会・ショップでご確認ください。

## アプリの使い方

1. [公開ページ](https://furuhashilab.github.io/Hackathon_Oct_SakuraNakamizo/)を開きます（ローカルでは `index.html` をブラウザで開くだけで動きます）。
2. 「診断をはじめる」を押し、3つの質問に答えます。「ひとつ前に戻る」で前の質問に戻れます。

   | 質問 | 選択肢 |
   | --- | --- |
   | Q1 ダイビングの経験はどのくらいですか？ | まったく初めて／ライセンスを取ったばかり／経験を積んでいる |
   | Q2 海の中でいちばん見たいものは？ | ウミガメ／サンゴと熱帯魚／迫力ある地形や魚の群れ |
   | Q3 どんなスタイルで楽しみたいですか？ | ビーチからのんびり／設備やほかの遊びも充実／ボートで沖へ |

3. 診断結果として、スポット候補が3件（「いちばんのおすすめ」と「候補2・3」）表示されます。各カードには島名・タグ・紹介文・ワンポイント・出典リンクがあります。
4. 「もう一度診断する」で最初からやり直せます。

### 診断の仕組み

- 各スポットは、質問の選択肢ごとに 0〜3 点の配点を持っています（`script.js` の `SPOTS`）。
- 3問の合計点が高い順に上位3件を表示します。
- 「まったく初めて」を選んだ場合、経験者向けのボートポイント（黒島北）は候補から外します。
