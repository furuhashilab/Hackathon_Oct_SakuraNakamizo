# 慶良間ダイビングスポット診断

慶良間諸島（沖縄県）限定の、初心者向け「ダイビングスポット診断」Webアプリです。
3つの質問に答えると、おすすめのスポット候補（上位3件）と紹介文が表示されます。

古橋研究室 オンラインハッカソン 2026 の制作物です。

## ⚠️ ご注意

- この診断は趣味・学習目的の簡易的なものです。**海況・安全性・生き物との遭遇を保証するものではありません。**
- 実際に潜る・泳ぐ際は、必ず現地のダイビングショップやガイドに相談し、当日の気象・海況情報と指示に従ってください。
- スポット情報は下記の公開資料をもとにまとめていますが、内容が変わっている可能性があります。最新情報は各村・観光協会・ショップでご確認ください。

## 使い方

1. `index.html` をブラウザで開きます（サーバー不要）。
2. 「診断をはじめる」を押し、3つの質問に答えます。
   - Q1：ダイビングの経験（まったく初めて／ライセンスを取ったばかり／経験を積んでいる）
   - Q2：見たいもの（ウミガメ／サンゴと熱帯魚／迫力ある地形や魚の群れ）
   - Q3：楽しみ方（ビーチからのんびり／設備やほかの遊びも充実／ボートで沖へ）
3. おすすめのスポット候補が3件表示されます。

## 仕組み

- 各スポットは、質問の選択肢ごとに 0〜3 点の配点を持っています（`script.js` の `SPOTS`）。
- 3問の合計点が高い順に上位3件を表示します。
- 「まったく初めて」を選んだ場合、経験者向けのボートポイント（黒島北）は候補から外します。
